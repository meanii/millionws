Transcribed by hand from the terminal session, not a raw file: the probe function and its output file were deleted right after use.

Probe: a throwaway AWS Lambda function (python3.12, outside the VPC, so not the operator's IP)
tried a TCP connect with a 4 s timeout to each port of the 250k-run server, about 2 minutes after apply,
before the server container was listening. Timeout = dropped by the network ACL; refused = reached the host.
